# Backend

This folder will hold the core API server for FitFlow.

## Planned Setup

- Node.js with Express
- PostgreSQL as the main database
- Firebase Firestore for real time features like the social feed and notifications
- Firebase Auth for login and sessions
- Redis for caching

## What This Service Handles

- User accounts and login
- Workout and nutrition data
- Talking to the AI service for recommendations and food recognition
- Coordinating real time updates through Firebase

The full reasoning behind these choices is in [docs/activity2-backend-db-auth-comparison.md](../docs/activity2-backend-db-auth-comparison.md).
