# Frontend

This folder will hold the FitFlow mobile app and web app.

## Planned Setup

- React Native for the iOS and Android app
- React for the web app, sharing as much code as possible with the mobile app

## Why React Native

React Native was picked because it lets the team build for iOS and Android from one codebase, has strong support for the camera, AI, and real time features FitFlow needs, and shares code easily with a React web app. The full comparison against Flutter, Kotlin Multiplatform, and Swift is in [docs/activity1-frontend-comparison.md](../docs/activity1-frontend-comparison.md).
